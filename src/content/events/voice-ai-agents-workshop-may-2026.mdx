## About the Host

**[Agora](https://www.agora.io/)** powers real-time voice, video, and interactive experiences at scale — trusted by thousands of developers worldwide to seamlessly embed communication into any application.

Agora Conversational AI helps you build real-time voice experiences faster, with the core components needed for speech-driven interactions in a single workflow. For workshop participants, this makes it easier to prototype voice agents, assistants, and interactive AI applications with less setup and more focus on the product experience.

You can also use **[TEN (Transformative Engagement Network)](https://github.com/TEN-framework/ten-framework)**, the Transformative Engagement Network, an open-source framework that supports modular voice AI development.

## Partners

**[TRAE (The Real AI Engineer)](https://www.trae.ai/)** is ByteDance's AI-powered IDE designed to change the way you build software. With IDE Mode providing smart coding assistance and [SOLO Mode](https://www.trae.ai/solo) enabling end-to-end automation, TRAE helps you turn natural language prompts into complete, working applications from scratch.

**[Couchbase](https://www.couchbase.com/)** provides an enterprise data platform built for modern applications, helping teams unify data, vectors, and AI workloads in a secure, scalable system. The platform is designed for mission-critical apps across cloud, mobile, edge, and AI use cases.
